\# 🧵 Todo Retazos \- Catálogo Virtual y Panel de Administración

Aplicación web interactiva desarrollada para \*\*Todo Retazos\*\*, orientada a la exhibición y gestión de un catálogo de telas, retazos y saldos textiles con sistema de consultas y pedidos directo a \*\*WhatsApp\*\*.

\---

\#\# ✨ Características Principales

\* \*\*Catálogo Público Interactivo:\*\*  
  \* Filtros por categoría (Punto, Plano, Gabardina, Tapicería, Frisa, etc.).  
  \* Filtro según la unidad de venta (Metro, Kilo, Unidad / Pack).  
  \* Buscador interactivo en tiempo real por nombre, código o composición.  
  \* Opciones de ordenamiento (Destacados, Novedades, Precio, Nombre).

\* \*\*Ficha Detallada de Productos:\*\*  
  \* Modal ampliado con galería de imágenes del producto.  
  \* Muestra composición, ancho/rendimiento y usos recomendados.  
  \* Selector de cantidad editable y campo para aclaraciones o notas del cliente.

\* \*\*Carrito / Pedido por WhatsApp:\*\*  
  \* Cálculo de subtotal estimado según las cantidades.  
  \* Generación de formato estructurado listo para enviar por mensaje al WhatsApp de la tienda.

\* \*\*Panel de Administración Integrado:\*\*  
  \* \*\*Acceso mediante credenciales:\*\*  
    \* \*\*Usuario:\*\* \`catalogotodoretazos@gmail.com\`  
    \* \*\*Contraseña:\*\* \`Bigotes202512\`  
  \* \*\*Gestión de Productos:\*\* Alta, edición, duplicación, eliminación y activación/ocultación de telas.  
  \* \*\*Carga de Imágenes Locales:\*\* Opción para subir fotos directamente desde el dispositivo (tanto para el logo de la página como para las fotos del catálogo).  
  \* \*\*Gestión de Categorías:\*\* Creación y control de rubros.  
  \* \*\*Respaldo de Datos:\*\* Exportación e importación de todo el inventario y configuración en formato \`.JSON\`.

\---

\#\# 🛠️ Tecnologías Utilizadas

\* \*\*HTML5\*\*  
\* \*\*Tailwind CSS\*\* (vía CDN para estilos responsivos)  
\* \*\*React 18\*\* & \*\*React DOM\*\* (vía CDN)  
\* \*\*Babel Standalone\*\* (para procesamiento de JSX en el navegador)  
\* \*\*Lucide Icons\*\* (librería de iconos vectoriales)  
\* \*\*LocalStorage API\*\* (persistencia de productos, carrito e imágenes en el navegador)

\---

\#\# 🚀 Instalación y Uso Local

1\. Clona o descarga este repositorio en tu computadora.  
2\. Abre el archivo \`index.html\` en cualquier navegador web moderno (Google Chrome, Firefox, Edge, Safari).  
3\. Para ingresar al panel de administración, haz clic en el botón \*\*"Administración"\*\* en el menú superior e ingresa las credenciales proporcionadas.

\#\# 🌐 Despliegue en GitHub Pages

Para publicar este catálogo de manera gratuita utilizando GitHub Pages:

1\. Ve a los \*\*Settings\*\* (Configuración) de tu repositorio en GitHub.  
2\. En el menú lateral izquierdo, busca la sección \*\*Pages\*\*.  
3\. En \*\*Source\*\* (Fuente), selecciona la rama \`main\` y la carpeta \`/ (root)\`.  
4\. Haz clic en \*\*Save\*\* (Guardar).  
5\. En unos minutos, GitHub te proporcionará una URL pública para acceder a tu catálogo en línea.
